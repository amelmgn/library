# Задание
Написать программу аналог библиотеки, которая должна уметь делать:
— добавить книгу
— получить список всех книг
— получить информацию о книге по id
— удалить книгу

# Описание

Программа представляет собой простую систему управления библиотекой книг с консольным интерфейсом.

## Структура проекта

- `main.py` - основной файл программы
- `README.md` - документация проекта

## Классы

### Book
Класс для представления книги в библиотеке.

**Атрибуты:**
- `id` - уникальный идентификатор книги (присваивается автоматически)
- `title` - название книги
- `author` - автор книги
- `year` - год издания (необязательно)

### Library
Класс для управления коллекцией книг.

**Методы:**
- `add_book(title, author, year=None)` - добавляет новую книгу и возвращает её ID
- `get_all_books()` - возвращает список всех книг
- `get_book_by_id(book_id)` - возвращает книгу по ID или None
- `delete_book(book_id)` - удаляет книгу по ID и возвращает удаленную книгу

## Функциональность

Программа отображает меню с следующими опциями:

1. **Add book** - добавление новой книги в библиотеку
2. **Show all books** - отображение списка всех книг
3. **Find book by ID** - поиск конкретной книги по её ID
4. **Delete book** - удаление книги из библиотеки
5. **Exit** - выход из программы

## Запуск программы

```bash
python main.py
```

## Особенности реализации

- Книги хранятся в словаре для быстрого доступа по ID
- ID генерируются автоматически и последовательно
- Год издания является необязательным параметром
- Обработка ошибок при вводе некорректных данных
